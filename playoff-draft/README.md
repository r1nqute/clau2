# Playoff Draft

NBA 플레이오프 카드 드래프트. 2015~2025년 플레이오프에 나간 팀(시즌마다 16팀, 모두 176팀)의 주전 다섯 명을 카드로 뽑아 5인 드림팀을 만들고, 역대 플레이오프 팀들과 8강 토너먼트를 치른다.

## 실행

```
cd playoff-draft
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

빌드 과정은 없다. `index.html`과 `data.js` 두 파일이 전부다.

## 규칙

1. **드래프트**: PG·SG·SF·PF·C 다섯 자리에 카드가 한 장씩 놓인다(3성 70% · 4성 25% · 5성 5%). 5성이 나오면 금빛 연출이 터진다. 같은 선수는 시즌이 달라도 한 팀에 두 번 들어가지 않는다.
2. **홀드 & 리롤**: 카드를 눌러 고정하고 나머지를 최대 세 번 다시 뽑는다(3성 70% · 4성 25% · 5성 5%). 리롤할수록 같은 팀·시즌 선수가 나올 확률이 10% → 20% → 30%로 오르고, 같은 팀 선수가 셋 이상 모이면 15%p가 더 붙는다.
3. **시너지** (카드당 최대 6성)
   - 같은 프랜차이즈 3~4장: 해당 카드 +1
   - 다섯 장이 모두 같은 시즌 / 같은 컨퍼런스: 전원 +1씩
   - 다섯 장이 모두 같은 프랜차이즈(프레스티지): 전원 +1
   - 다섯 장이 모두 같은 팀·같은 시즌(레전더리): 전원 +2
4. **올타임 플레이오프**: 로스터를 확정하면 역대 플레이오프 팀 일곱과 8강 → 4강 → 결승을 치른다. 모든 시리즈는 7전 4선승제이고, 팀 점수 차이가 경기마다 이길 확률을 정한다.
5. **자유 모드**: 도감에 등록된 선수로 다섯 자리를 마음대로 채운다. 이름·팀·시즌으로 찾고 등급·득점·최신순으로 정렬할 수 있다. 시너지와 토너먼트는 똑같이 적용되지만, 업적은 드래프트 모드에서만 얻는다.

뽑힌 카드는 모두 **도감**에 쌓이고, 한 팀·한 시즌의 다섯 명을 다 모으면 **갤러리**에 그 팀이 완성된다. **업적**은 8개다. 기록은 브라우저(localStorage)에만 저장된다.

## 카드 등급

| 팀 성적 | 등급 |
| --- | --- |
| 우승 | 5성 |
| 파이널 준우승 · 컨퍼런스 파이널 | 4성 |
| 2라운드 · 1라운드 | 3성 |

플레이오프 평균 25점 이상이거나, 팀 내 최다 득점이면서 22점 이상인 선수는 **에이스**로 1성을 더 받는다(최대 5성).

## 데이터

`data.js`는 Basketball-Reference의 시즌별 플레이오프 페이지와 팀 페이지에서 만들었다.

- 팀: 그해 플레이오프 시리즈 표에 나온 16팀과 각 팀이 치른 시리즈 결과
- 주전 다섯: 그 팀의 플레이오프 경기당 기록에서 선발 출전이 가장 많은 다섯 명(같으면 출전 시간 순). 다섯 명을 PG~C에 앉힐 때는 등록 포지션에 가장 가깝게 배치하고, 동률이면 리바운드가 많은 선수를 안쪽 자리로 보낸다.
- 등번호와 플레이오프 평균 득점·리바운드·어시스트도 함께 담았다.

NBA나 각 구단과는 관계없는 팬 제작 게임이다.
