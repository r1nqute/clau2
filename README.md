# 칼 너머

칼 한 자루 차고 물 건넌 이야기.

고려에는 더 겨룰 사람이 없던 검객이 바다를 건넌다. 고갯마루의 도리이를 하나 지날 때마다 백 년쯤이 지나 있고, 그때마다 그 시대에 가장 세다는 사람이 있다. 「재 너머」와 같은 화풍·같은 말투로, 판을 훨씬 키웠다.

브라우저에서 바로 도는 도트 액션 게임이다. 빌드 과정이 없다.

## 실행

```
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 바로 열면 글꼴을 못 읽는 브라우저가 있어서, 작은 서버를 하나 띄우는 편이 낫다.

## 조작

들에서 걷다가 보이는 적에 닿으면 싸움이 된다. 싸움은 차례를 주고받는 JRPG식이다.

| 들에서 | 키 | 손가락 |
| --- | --- | --- |
| 걷기 · 달리기 | 방향키 / WASD · Space를 누른 채 | 왼쪽 원판 · 달리기 |
| 말 걸기 · 살피기 | Z 또는 X | 치기 · 살피기 |
| 적의 등 뒤에서 먼저 치기 | Z | 치기 |
| 팔척뛰기(얻은 뒤) | C | 뛰기 |
| 먹기 · 봇짐 · 지도 · 소리 | V · Esc · M · 0 | 먹기 · 봇짐 · 지도 |

| 싸움에서 | 하는 일 |
| --- | --- |
| 베기 | 한 칼. 기가 조금 찬다. |
| 비기 | 기를 써서 크게 벤다(발도, 팔척뛰기, 허수, 일지태도, 수레걸이, 제비 돌리기). |
| 쳐내기 | 흰 수 하나를 쳐내고 되받아친다. 저쪽 자세가 흔들리고 기가 찬다. |
| 비키기 | 붉은 수를 비킨다. 헛친 쪽이 휘청이고 기가 찬다. |
| 막기 | 무엇이든 덜 아프게 받는다. |
| 도구 · 보내기 · 물러나기 | 먹고 마신다 · 칼을 버린 자를 보내 준다 · 싸움에서 빠진다(맞수와는 못 한다). |

방향키로 고르고 Z(또는 X)로 정한다. C나 Space는 한 단계 물린다.

- 차례마다 저쪽이 무엇을 하려는지 **기색**이 위 창에 먼저 뜬다. 흰 번쩍임은 쳐낼 수 있고, 붉은 번쩍임은 비켜야 하고, 초록 글씨는 틈이다.
- 흰 네모는 막는 자세(베기는 덜 든다, 비기로 뚫는다), 금빛 네모는 받아칠 자세(베면 되받는다, 기다린다).
- 여럿이 한꺼번에 오면 쳐낼 수 있는 것은 하나뿐이다. 여러 번 치는 수는 첫 칼만 쳐낼 수 있다.
- 자세(노란 줄)가 무너진 맞수는 크게 벨 수 있다.
- 산 것은 한 칼에 죽지 않는다. 기가 꺾여 칼을 버리면, 보내 줄지 한 번 더 벨지는 하는 사람이 정한다.
- 이기면 수련이 쌓여 경지가 오르고, 체력과 힘이 붙는다. 맞수에게 이기면 비기를 얻는다.
- 고갯마루의 짚단을 치면 덴구가 연습 상대가 되어 준다.
- 지장 앞에서 새기고 쉰다. 쓰러지면 마지막 지장 앞에서 깬다. 승부에서는 누구도 죽지 않는다. 칼은 한 치 앞에서 멎는다.

## 역사에 대하여

사람과 때와 곳은 기록에서 가져왔고, 주인공과 그가 끼어드는 승부는 지어낸 것이다. 봇짐의 「인물록」에 사람마다 **기록에 남은 것**과 **전하는 이야기**를 나누어 적었다. 요시쓰네의 여덟 척 뛰기, 벤케이의 선 채로 죽음, 보쿠덴의 무수승류, 겐신의 세 칼과 소금, 무사시의 노 같은 것은 뒷날의 책에 실린 이야기이고, 게임에서도 그렇게 밝힌다.

## 파일

```
index.html        화면과 손가락 조작
js/core.js        난수, 입력, 효과음, 가락, 도트 글자, 저장
js/art.js         사람·짐승·맞수 도트(글자 격자)
js/art2.js        나무·집·도리이·깃발(코드로 그린 것)
js/world.js       타일, 철마다 다른 빛깔, 지도 짓는 연장
js/maps*.js       지도 열 장
js/data.js        물건, 비기, 인물록, 혼잣말
js/fx.js          칼자국, 잔상, 날씨, 멈춤
js/entities.js    들에 보이는 적과 짐승, 굴러오는 통나무
js/player.js      들에서의 주인공(걷기, 달리기, 먼저 치기, 팔척뛰기)
js/boss.js        맞수를 들에 세우고 승부로 넘기는 것
js/foes.js        잡것과 맞수마다의 수와 기색, 때마다의 세기
js/battle.js      차례 싸움
js/ui.js          대화, 가게, 봇짐, 승부 알림
js/story*.js      사람들 말과 이야기 진행
js/main.js        판 돌리기
tools/            그림·지도 확인용 쪽, 아티팩트용 변환
```

그림 파일과 소리 파일은 없다. 도트는 코드 안의 글자 격자이고, 효과음과 가락은 Web Audio로 그때그때 만든다.
