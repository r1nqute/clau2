# 칼 너머

칼 한 자루 차고 물 건넌 이야기.

고려에는 더 겨룰 사람이 없던 검객이 바다를 건넌다. 고갯마루의 도리이를 하나 지날 때마다 백 년쯤이 지나 있고, 그때마다 그 시대에 가장 세다는 사람이 있다. 「재 너머」와 같은 화풍·같은 말투로, 판을 훨씬 키웠다.

브라우저에서 바로 도는 도트 액션 게임이다. 빌드 과정이 없다.

## 실행

```
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 바로 열면 글꼴을 못 읽는 브라우저가 있어서, 작은 서버를 하나 띄우는 편이 낫다.

## 조작

| 동작 | 키 | 손가락 |
| --- | --- | --- |
| 걷기 | 방향키 / WASD | 왼쪽 원판 |
| 베기 (이어 누르면 세 수) | Z / J | 베기 |
| 발도 (꾹 눌렀다 뗀다) | Z / J | 베기 길게 |
| 막기 · 맞는 순간 누르면 쳐내기 · 말 걸기 | X / K / Enter | 막기 |
| 보법 (뒤이어 베기를 누르면 달려 베기) | Space / Shift | 보법 |
| 비기 · 비기 바꾸기 | C / L · Q | 비기 · 바꿈 |
| 먹기 | V / F | 먹기 |
| 봇짐 · 지도 · 소리 끄기 | Esc / I · M · 0 | 봇짐 |

- 흰 번쩍임은 막거나 쳐낼 수 있다. 붉은 번쩍임과 붉은 자리는 비켜야 한다.
- 막기만 하면 내 자세가 무너진다. 쳐내면 저쪽 자세(노란 줄)가 무너지고, 그때가 벨 때다.
- 칼을 버리고 달아나는 자는 칼끝이 저절로 따라가지 않는다. 벨지 보낼지는 하는 사람이 정한다.
- 지장 앞에서 새기고 쉰다. 쓰러지면 마지막 지장 앞에서 깬다.
- 승부에서는 누구도 죽지 않는다. 칼은 한 치 앞에서 멎는다.

## 역사에 대하여

사람과 때와 곳은 기록에서 가져왔고, 주인공과 그가 끼어드는 승부는 지어낸 것이다. 봇짐의 「인물록」에 사람마다 **기록에 남은 것**과 **전하는 이야기**를 나누어 적었다. 요시쓰네의 여덟 척 뛰기, 벤케이의 선 채로 죽음, 보쿠덴의 무수승류, 겐신의 세 칼과 소금, 무사시의 노 같은 것은 뒷날의 책에 실린 이야기이고, 게임에서도 그렇게 밝힌다.

## 파일

```
index.html        화면과 손가락 조작
js/core.js        난수, 입력, 효과음, 가락, 도트 글자, 저장
js/art.js         사람·짐승·맞수 도트(글자 격자)
js/art2.js        나무·집·도리이·깃발(코드로 그린 것)
js/world.js       타일, 철마다 다른 빛깔, 지도 짓는 연장
js/maps*.js       지도 열 장
js/data.js        물건, 비기, 인물록, 혼잣말
js/fx.js          칼자국, 잔상, 날씨, 멈춤
js/entities.js    적과 짐승, 날아가는 것, 맞고 때리는 셈
js/player.js      주인공의 동작
js/boss*.js       승부의 틀과 맞수마다의 수
js/ui.js          대화, 가게, 봇짐, 승부 알림
js/story*.js      사람들 말과 이야기 진행
js/main.js        판 돌리기
tools/            그림·지도 확인용 쪽, 아티팩트용 변환
```

그림 파일과 소리 파일은 없다. 도트는 코드 안의 글자 격자이고, 효과음과 가락은 Web Audio로 그때그때 만든다.
