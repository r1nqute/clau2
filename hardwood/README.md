# 하드우드 매니저

실제 NBA 역사 위에서 펼치는 농구 감독 시뮬레이션. 풋볼 매니저(FM) 같은 방식으로, 한 구단을 맡아 선수단·전술·트레이드·자유계약·드래프트를 꾸리며 시즌을 이어 간다.

- **시작 시즌을 고른다**: 1977-78 시즌(ABA 합병 직후)부터 지금 진행 중인 2026-27 시즌까지 50개 시즌.
- **그 시즌의 실제 NBA**: 실제 팀(이름·연고·지구 편성)과 실제 로스터로 시작한다. 선수 능력치는 그 시즌의 실제 기록에서 계산한다.
- **실제 커리어 따라가기**(기본): 실존 선수는 현실의 성장·노쇠 곡선을 약간의 편차와 함께 따른다. 미래 드래프트에는 실제로 그해 뽑힌 선수들이 나오고(2003년에는 르브론), 실제 연고 이전·팀명 변경도 그 해에 일어난다. 실제 자료가 끝나는 2027년 이후는 가상의 유망주로 이어진다.
- **무작위 성장**을 고르면 시작 시점부터 역사가 갈라진다.

## 실행

빌드가 필요 없다. 아무 정적 서버로 이 폴더를 열면 된다.

```
cd hardwood
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

한 파일짜리가 필요하면 `node tools/bundle.mjs`로 `dist/hardwood-manager.html`을 만든다. 이 파일은 서버 없이 바로 열어도 돈다.

claude.ai 아티팩트로 올릴 때는 `node tools/artifact.mjs <폴더>`로 페이지(`index.html`)와 따로 불러올 `data/nba.json`을 만든다.
다른 페이지 안에 들어가 있으면 주소의 `#/화면` 대신 페이지 안에서 화면을 옮기고, 자료는 `data/nba.json`에서 읽는다.

저장은 브라우저(IndexedDB)에 자동으로 된다. 다른 기기로 옮길 때는 **저장·설정 → 파일로 내보내기**, 타이틀 화면의 **저장 파일 불러오기**를 쓴다.

### 지루한 부분 건너뛰기 · 턴 끄기

- 위쪽 **계속 ▾** 메뉴: 하루 / 1주일 / 1개월 / 트레이드 마감까지 / 정규시즌 끝까지 / 시즌 끝까지 / **오프시즌 건너뛰기** / **다음 시즌 개막까지**.
- 생중계 중: **다음 쿼터로**, **4쿼터 막판(5분)으로**, **끝까지** 건너뛰기.
- **저장·설정 → 자동 진행(턴 끄기)**: 우리 경기 날 멈추기(모든 경기·플레이오프만·멈추지 않음), 멈췄을 때 경기 방식(매번 묻기·바로 생중계·바로 결과),
  코치에게 맡길 단계(프리시즌·드래프트·재계약·자유계약 시장), 하프타임 정지·AI 트레이드 제안·가벼운 부상 알림 켜고 끄기.
  "빠르게: 지루한 부분 모두 자동" 한 번으로 정규시즌은 자동, 플레이오프만 직접, 오프시즌은 코치에게 맡기는 설정이 된다.
- 경기를 멈추지 않게 해 두면 **계속**은 1주일씩 진행하고 그 주의 승패를 알려 준다.

### 관심 FA 알림

- **자유계약** 화면의 거르기: 포지션, 최소 능력·잠재력, 나이 범위, 최대 요구 연봉, 특정 능력치(예: 3점 슛 15 이상).
- **🔔 이 조건으로 알림 받기**: 거르기를 알림 조건으로 저장한다. 조건에 맞는 선수가 시장에 새로 나오면(재계약 결렬, 방출, 드래프트 미지명, 실제 선수 합류) 받은 편지함으로 알리고, 진행을 멈추고 창을 띄운다(설정에서 끌 수 있다).
- **★ 관심 선수**: 어느 팀 선수든 선수 화면이나 **예정 FA** 탭에서 등록하면, 그 선수가 시장에 나오는 날 알려 준다.
- **예정 FA** 탭: 올 시즌이 끝나면 계약이 끝나는 다른 팀 선수들.

### 매니저 모드(🧠 수석 코치)

- **수석 코치 보고서** 화면:
  - 팀 진단: 3점·골밑·볼 운반·리바운드·림 보호·외곽 수비·운동 능력·경기 운영·공격력·수비력·벤치 깊이를 리그 순위로(강점/약점 표시)
  - 포지션 뎁스: PG~C별 선수와 부족·과잉 판단(인접 포지션 대체 고려)
  - 영입 추천: 약점·부족 포지션을 채울 FA(바로 협상), 상대가 받아 줄 묶음까지 맞춰 본 트레이드 대상(예상 대가 표시, 우리 핵심 두 명은 빼고)
  - 정리 추천: 연봉 대비 능력, 출전 기회, 나이, 포지션 중복, 장기 부상으로 본 방출·트레이드 후보와 방출 시 잔여 연봉
  - 전술 추천: 선택지마다 100포제션당 효과를 경기 엔진과 같은 공식으로 계산, 한 번에 적용
- **경기 전**: 상대의 강점·약점, 핵심 선수, 결장자, 그 상대에 맞춘 추천 전술(적용 단추).
- **경기 중**: 생중계에 코치 조언(체력, 파울 트러블, 상대 3점, 페인트존 실점, 턴오버, 리바운드, 클로징 라인업, 추격·굳히기)과 적용 단추. "코치에게 맡기기"를 켜면 코치가 알아서 조정한다(결과만 보기 경기에도 적용 가능).
- **월간 코치 보고서**를 받은 편지함으로 받는다.

### 다크 모드

기본이 다크 모드다. 위쪽 막대(타이틀 화면은 오른쪽 위)의 🌙/☀️ 단추로 바로 바꾸고, 설정에서 "기기 설정 따르기"도 고를 수 있다.

정규시즌이 끝나면 MVP·올해의 수비수·신인왕·식스맨·기량발전상·올-NBA를 뽑고, 파이널 뒤에는 파이널 MVP와 은퇴, 드래프트, 재계약, 자유계약 시장, 새 시즌(성장·노쇠)으로 이어진다. 성적이 이사회 기대에 크게 못 미치면 해임되고, 다른 구단을 맡을 수 있다.

## 자료와 계산

- 원자료: Basketball-Reference 기록을 모은 [sumitrodatta/bball-reference-datasets](https://github.com/sumitrodatta/bball-reference-datasets) (1947~2026-27 시즌 초).
- `tools/build-data.mjs`가 시즌마다 선수 기록(그 해·작년·재작년을 섞고 표본이 적으면 사전값 쪽으로 당김)을 백분위로 바꿔 능력치의 모양을 만들고, 실제 공헌도(OBPM·DBPM)에 맞도록 높낮이를 맞춘다. 이렇게 만든 능력치로 계산한 팀 전력은 실제 팀 성적(SRS)과 상관계수 0.96~0.98이다.
- 경기 엔진(`js/sim.js`)은 포제션 단위로 돈다. 코트 위 다섯 명의 공헌도로 포제션당 기대 득점을 정하고, 개별 능력치는 누가 슛을 하고, 넣고, 리바운드·어시스트·스틸을 하는지를 정한다. 시즌마다 실제 리그 템포와 효율을 쓴다. 실제 로스터로 한 시즌을 돌리면 팀 승률이 실제와 상관계수 약 0.85, 리그 평균 득점은 실제와 1점 안쪽이다(`node tools/calibrate.js 2010`).
- 계약 금액은 실제 계약이 아니라 선수 능력과 그 해의 실제 샐러리캡으로 추정한 값이다. 1984-85 이전에는 당시 연봉 수준에 맞춘 가상의 캡을 쓴다.
- 선수 이름은 Basketball-Reference의 현재 표기를 따른다(예: Ron Artest는 Metta World Peace로 나온다).
- 팀 확장(새 구단 창단)은 아직 없다. 시작할 때의 팀들로 리그가 이어지며, 실제 연고 이전·팀명 변경만 반영한다.

이 게임은 NBA와 관계없는 팬 제작 시뮬레이션이다.

## 자료 다시 만들기

```
git clone --depth 1 https://github.com/sumitrodatta/bball-reference-datasets.git /tmp/bref
node tools/build-data.mjs /tmp/bref/Data       # data/nba.js
node tools/calibrate.js 2010                    # 엔진 점검(실제 로스터로 한 시즌)
node tools/smoke.js 2003 CLE 3                  # 여러 시즌을 머리 없이 끝까지
```
